# 사이퍼링크 v0.10.3 — 사용자 Todoist 실제 작업 제목 연결 (Android + Windows PC)

기준: 2026-10-28에 전달된 DoDoGames Todoist 화면 2장. 기존 작업은 **제목 변경·삭제·새로 생성하지 않습니다**. 두 플랫폼은 `todoist_bindings.json`을 동일한 형식으로 사용합니다.

## 직접 변경한 부분

- `android/app/src/main/assets/todoist_bindings.json` / `pc/todoist_bindings.json`: 실제 작업 제목 34개(기존 매핑 `[원신] 나선` 포함)를 기록. 자동 가능 / 인증 조건부 / 수동을 명시.
- Android `AccountSync.kt`: 소스 내 하드코딩된 제목 대신 위 JSON의 `status=auto` 연결만 읽어서 현재 회차의 일치하는 Todoist 제목을 찾습니다. 기존 게임별 조회 ON/OFF·기간 확인·2회 확인·중복 방지 기능을 보존합니다.
- Windows `gametodo/task_rules.py`: 동일한 JSON에서 자동 및 안전 정책상 조건부 항목을 읽고 기존 개별 제목 재정의(custom_bindings)도 보존합니다.
- PC `gametodo/live_data.py`: 실제 스크린샷의 `[원신] 주간보스`와 `[열차] 주간퀘스트`에 대응하는 주간 게이지 보강. `[젠존제] 주간퀘`는 Android와 같은 2개 조건 모두 충족시만 완료. 미검증 필드는 완료하지 않습니다.
- Windows `build_windows.bat`: PyInstaller 빌드 시 신규 JSON 포함 (`--add-data` 옵션). 기존 배치 파일의 CP949 인코딩 유지.

## 등록·분류만 하고 자동 완료하지 않은 항목

- 명조 글로벌: `[명조] 일퀘`, `[명조] 주간퀘`, `[명조] 탑`, `[명조] 폐허`, `[명조] 매트릭스`. 글로벌 진행도 API가 검증되지 않아 자동 체크하지 않습니다. PC 과거 `tower` 연결도 실제 글로벌 조회가 불가능한 동안 동작하지 않습니다.
- 명일방주: `[명방] 일퀘` (PC 23:59 인증 조회 명시적 허용 및 API 증거가 있어야만 조건부), `[명방] 섬멸작전 1800개`는 미연결/수동.
- 림버스: `[림컴] 엔케팔린 소모`, `[림컴] 거던`은 수동.
- 리버스 1999: `[립9] 일퀘`, `[립9] 심면구역`, `[립9] 갈기의 게시판1/2/3`은 수동.
- 스텔라 소라: `[스소] 일퀘`, `[스소] 연합토벌`, `[스소] 재앙의전선`, `[스소] 종언의 노래`는 수동.
- 원신: `[원신] 지제전`은 스크린샷 제목 그대로 분류만 하고, 검증된 개인 진행도 API가 없어 자동 완료하지 않습니다.
- 컬러스위퍼 `[색지뢰] 일퀘`는 요청에 따라 자동화에서 제외.
- 이벤트/가챠 섹션은 기존 별도 가챠 처리 정책 유지; 자동 일퀘·엔드 콘텐츠로 연결하지 않습니다.

## 주의할 점

- 연결은 **작업 제목 정확히 일치 + 게임 식별** 방식입니다. 앱이 사용자의 Todoist에 직접 접속해 제목을 수정하는 작업은 수행하지 않습니다.
- `due.date`와 현재 게임 회차를 별도로 검사하며, 유효한 회차 기록/점수가 없으면 자동 완료하지 않습니다.
- PC의 `game_rules.json`과 Android 자산의 접두사·라벨 규칙은 변경하지 않았습니다.
- 기존 `0.10.2` 설정 및 로그인 자료를 지우지 마세요. Android는 기존 앱 위에 같은 서명으로 설치해야 정보가 유지됩니다.

## Android(Termux) 업데이트

```sh
ZIP="$(ls -t ~/storage/downloads/CipherLink_Android_v0.10.3*.zip | head -n 1)"
[ -n "$ZIP" ] || { echo 'Android v0.10.3 ZIP을 다운로드 폴더에 저장하세요'; exit 1; }
unzip -o "$ZIP" -d ~/projects/gametodo
studio build ~/projects/gametodo/android :app:assembleDebug
cp ~/projects/gametodo/android/app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/CipherLink-v0.10.3.apk
```

## PC 업데이트

PC ZIP을 기존 Windows 프로젝트에 덮어쓰되, `config.json`과 기존 학습·저장 파일 등 사용자 데이터는 덮어쓰지 않습니다. `pc/run_windows.bat`으로 기존 방식대로 실행. 배포 EXE를 직접 다시 만든다면 `pc/build_windows.bat`을 사용합니다.
