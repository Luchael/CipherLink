# 0.11.2: 진행도 조회와 새 게임 연결

## 사용자 제보와 재현

- 진행도 버튼을 처음 누르면 “지금 작업을 마무리하고 있어요”가 뜨고 기존 작업이 실패한 뒤 재시도해야 진행됨.
- `MainActivity.startJob`의 실제 함수 본문을 JVM 재현기에 넣어 첫 작업을 latch로 정지하고 진행도 버튼을 호출했다. 기존 구현은 `if(working) ... return`으로 두 번째 요청을 버림. 재현 결과 `Progress click was discarded while first job was running`으로 실패했다.
- 확인 가설: 기존 작업의 전역 busy 플래그가 요청을 버리는 문제, 브라우저 인증/가챠 조회가 같은 실행기를 점유하는 문제, 메모의 같은 필드 중복 표시. 앞의 두 원인은 코드와 재현으로 확인했으며 실제 기기에서 앞선 네트워크 요청이 왜 실패했는지는 미검증.
- `UiJobRunnerTest`는 첫 동기화가 정지하고 실패하는 동안에도 첫 진행도 요청이 성공함을 검증한다. 같은 작업의 연속 탭은 합치고, 실패 후 재시도와 종료도 검증한다.

## 수정 내용

- Android `UiJobRunner`/`MainActivity`: 서로 다른 UI 작업은 별도 실행(최대 3개), 같은 작업 중복 요청 방지. 항상 보이는 상단 로딩 스피너와 단계별 조회 문구, 조회 중 버튼 표시. 수동 동기화는 계정 목표를 가챠 일정보다 먼저 확인한다. 자동 완료의 회차/점수/UUID 정책은 그대로 유지한다.
- Android `WeeklyProgress`/`AccountProviders`, PC `live_data`: 사용자 지정 스타레일 통합 목표 **18000점 이상 AND 역전의 여운 주간 보상 잔여 0/3**. API 계정별 최대치가 12000이라도 12000점으로 완료하지 않으며, 실제 현재 점수/보상 필드가 없거나 보상 범위가 틀리면 완료하지 않는다. 18000점은 사용자 지정 목표이지 추정 API 값이 아니다.
- Android/PC 진행도 표시: 통합 포인트와 주간 보상 구성 조건을 표시. 보상 게이지는 사용 횟수로 채우되 숫자는 `잔여 0 / 3`으로 표시한다. `ProgressMemo`는 이미 게이지에 표시한 값을 반복하지 않고 자원/파견 등 부가 정보만 한 번 표시한다. 알려진 상태 enum도 한국어로 표시한다.
- Android `FloatingOverlay`: 게임에 관계없이 사이퍼링크 아이콘을 버튼에 사용한다. 설정의 연결 목록에서는 각 게임 앱 아이콘을 사용한다.
- 앱 선택창: 앱 이름/패키지 검색, 검색 결과 수, 검색 결과 없음 안내, 현재 연결 라벨 표시. 추천 목록에서도 입력하면 모든 실행 가능한 설치 앱을 검색한다.
- `LabelGames`/`GameRules`: Todoist의 실제 미완료 작업 라벨을 읽고 사용자가 게임 라벨을 선택해 등록한다. 같은 라벨은 같은 게임 키를 사용한다. 앱 연결창에서도 새 게임을 추가할 수 있다. 사용자 정의 게임에는 수동 할 일 표시/완료만 제공하며 미확인 점수 API로 자동 완료하지 않는다. 부모의 라벨/예정일 상속, 충돌 라벨 차단, 이벤트/미래 일정 제외를 유지한다.
- 공유 Todoist 바인딩 JSON의 설명과 제품 문서를 같은 18000점 기준으로 갱신했다. 작업 제목/기존 패키지 매핑/Keystore/사용자 데이터는 이동하지 않는다.

## 기기에서 확인할 방법

1. 기존 설치 앱을 삭제하지 않고 0.11.2 APK로 업데이트한다. 동기화를 누른 직후 진행도 버튼을 눌러 첫 클릭이 실행되고 상단에 현재 게임/로딩이 표시되는지 확인한다.
2. 스타레일 화면에서 통합 포인트 `/18000`, 보상 `잔여 0 / 3`, 중복 메모가 사라졌는지 확인한다. 실제 Todoist 완료는 현재 회차의 예정일 등 기존 조건도 만족해야 한다.
3. 설정 → 게임 앱 연결 → 모든 앱 보기에서 앱 이름을 검색한다. 새 게임은 Todoist에서 같은 게임 라벨을 미완료 할 일에 붙이고, 앱 연결창의 “Todoist 라벨로 새 게임 추가”로 연결한다. 할 일의 예정일은 오늘 또는 과거여야 보인다.
4. 게임을 실행해 사이퍼링크 플로팅 아이콘과 해당 게임의 할 일을 확인한다. 문제가 남으면 오류 문구, 발생 단계와 대기 시간만 알려준다. 인증 URL/비밀번호/쿠키/토큰은 공유하지 않는다.
