# 제품 요구사항 / Todoist 동작 기준

## 목표·운영 환경

- Windows + Android 독립 앱, 같은 Todoist 계정 동기화. 무료 운영, 외부 장비 불필요, 배터리/트래픽 최소화. 한국 서버가 별도 있으면 KR, 없으면 글로벌 Asia. 한국어 UI/KST.
- 모바일이 주 실행 기기이며 PC 상시 실행을 전제하지 않음. 기기 모델/스토어를 고정하지 않고 Play·갤럭시·원스토어 앱은 설치 앱 연결로 지정. WorkManager의 실행 지연/절전 제한과 실기기 검증을 구분.
- 지원 대상(기본 목록): 원신, 붕괴: 스타레일, 젠레스 존 제로, 명조(글로벌), 리버스 1999, 림버스 컴퍼니, 명일방주(KR/글로벌 가능하면), 명일방주: 엔드필드, 스텔라 소라. 프로젝트 세카이·작혼·홀로라이브 등은 초기 희망 목록이었지만 현재 소스에서 개인 진행도 자동 판정 여부는 별도 검증 필요. 컬러스위퍼는 후속 사용자 요청으로 `[색지뢰] 일퀘` 수동 체크 전용 재포함.
- 게임별 접두사·라벨과 정확한 Todoist 작업 제목은 **`pc/todoist_bindings.json`**, Android 동일 경로의 JSON 및 `game_rules.json`이 진실의 원천. 임의 rename/migration 금지.
- 캘린더/반복 섹션: 일일, 주간, 월간, N일 주기, 이벤트/기간 한정(가챠). 이벤트/가챠는 일반 플로팅·자동 일퀘와 섞지 않음.

## 회차/초기화/중복 안전

- **정확한 현재 회차만 자동 완료**. API가 과거 기록도 반환할 수 있으니 필요한 때에는 현재 시즌/시작 종료일로 판별. Todoist 예정일이 유효한지는 별도 검증.
- Todoist `due.date`가 오늘/과거라도 **오늘의 서버 초기화 전**에는 해당 회차의 작업을 체크하지 않는다. Android 플로팅은 과거의 미완료 작업을 표시하되, 초기화 전 오늘 예정 작업은 숨김.
- 초기화 직후 유예, 2분 이상 간격 두 번 확인 등 기존 API 자동 완료 안전 정책 유지.
- PC·Android 중복 완료/등록 방지: 동일한 Todoist Sync API 명령 UUID/작업 확인 규칙. 자동 재시도 시 중복 방지.
- 사용자 TODO의 시작일/반복/하위 작업을 잘못 수정하거나 완료해서는 안 된다.
- `[젠존제] 주간퀘` 하위 작업인 `주간퀘스트(폴리크롬 최대치)`는 별도의 자동완료 작업에 연결되어 있지 않다. 부모만 자동 완료하는 현 정책 유지.

## 가챠

- 현재 진행 중인 **캐릭터 픽업만** Todoist 이벤트/기간 한정에 등록. 일반 이벤트나 무기 전용 배너 제외.
- 접두사 + 캐릭터 이름(버전/버전명 포함), 설명=출처, 시작일=가챠 시작일. 종료일이 지나면 완료 처리; 무료 Todoist 제한 보완.
- 서버/시간대 출처 검증과 가챠 중복 생성 방지 필수. 사용자는 명조 중국 가챠 일정 사용을 허용함. 현재 한국어/KST PickupCal 명조 파서를 연결했지만 live 응답은 네트워크 차단으로 미검증. 중국 공식 Wiki 직접 수집은 한국어 이름·시각 스키마 검증 후 추가. 개인 글로벌 진행도는 별도로 검증해야 함.

## UI / 플로팅

- Android 플로팅은 현재 포그라운드 게임에서만, 실제 게임 아이콘만 보이는 **작은 드래그 가능한 원형** 버튼. 가챠/완료/체크 금지 작업 제외. 게임을 떠나면 숨김.
- 자동 확인 ON/OFF는 일반 Android **슬라이드 토글 스위치**, 현재 상태 문구, 사용자 선택 간격(15분~24시간 등). 게임별 조회 토글 존재.
- PC UI는 사이드바 메뉴/카드형 상태, 계정 연결, 진단/로그 가독성. 동일 아이콘 사용.
