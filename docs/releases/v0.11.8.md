# 사이퍼링크 0.11.8

- 게임 초기화 시각과 실제 API 회차를 함께 검사해 이전 기록으로 새 할 일이 완료되는 문제 수정
- PC·Android 게임별 초기화 시각 설정 추가
- 플로팅에서 이름·날짜·반복·프로젝트·섹션으로 할 일 추가 및 재시도 중복 방지
- 플로팅 아이콘 이동, 화면 회전과 노치·시스템 영역 경계 처리 개선
- Windows 설치판은 기존 위치 업데이트와 제거, 기존 계정·설정·데이터 보존 지원

이 릴리스의 설치 파일은 Windows용입니다. `CipherLink-Windows-Setup.exe`로 설치하거나 업데이트하세요. 무설치판은 `CipherLink-Windows.exe`입니다.

Android 0.11.8은 소스와 서명 없는 빌드까지 준비됐습니다. 기존 앱과 업데이트 호환성을 유지할 개인 서명키가 현재 환경에 없어 설치용 APK는 포함하지 않습니다. 기존 0.11.7 APK를 새 버전으로 표시하지 않으며 기존 앱을 삭제할 필요도 없습니다.

게임별 공식 초기화 시각 전체 재검증, 실제 계정 API·사용자 Windows·Android17 실기기 동작은 별도 검증이 필요합니다.
