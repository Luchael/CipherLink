# 사이퍼링크 0.11.9

Windows 설치판·무설치판과 Android APK를 함께 제공합니다.

- 새 Android 개인 서명키를 사용하고 이후 동일 키로 업데이트할 정식 설치 계열을 시작합니다.
- 기존 앱의 데이터가 삭제되지 않도록 Android 패키지를 `com.gametodo.cipherlink`로 분리했습니다.
- 버전을 main에 반영하면 태그 생성, Windows·Android 빌드, APK 서명 검증, 릴리스 게시와 README 상단 다운로드 갱신을 자동으로 수행합니다.
- 초기화 날짜·시각과 API 회차 검사, 플로팅 할 일 추가·중복 방지·이동 개선을 포함합니다.

## Android 첫 설치

기존 0.11.7/이전 앱의 **자동 확인과 게임 감지를 먼저 끄세요.** 새 APK를 설치하고 Todoist·게임 계정 연결과 접근성·알림 권한을 다시 설정합니다. 기존 앱과 데이터는 유지되며, 자동 이전되지는 않습니다. 새로 설치한 앱의 설정에서 버전 0.11.9를 확인할 수 있습니다.

이후에는 같은 패키지와 서명으로 업데이트합니다. 개인 서명키는 공개 릴리스에 포함하지 않습니다.

Windows 설치판은 기존 설치 위치에 업데이트하고 계정·설정·DB를 보존합니다. 실계정 API·Android17 기기·사용자 Windows에서의 실제 동작은 별도 확인이 필요합니다.
