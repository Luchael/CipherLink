# 사이퍼링크 0.11.11

- PC·Android에서 시유 방어전 미도전이 정상 확인되면 **기록 없음**으로 표시합니다. 진행 막대를 숨기고 조회 실패와 구분합니다.
- 일부 전선 기록만 있더라도 확인된 S 개수를 표시합니다. 신형 시유는 제4전선 S + 제5전선 세 방 각각 S, 총 4/4 S로 판단합니다.
- 별 개수·종합 S+·점수 추정으로 시유를 완료하는 대체 경로를 제거했습니다. 통과가 불확실한 기록은 S 개수를 그대로 보여주면서 자동 완료를 보류합니다.
- SDK의 신·구형 응답과 구형 `all_floor_detail`/`rating_list`를 지원하고, 해석할 수 없는 응답에는 개인정보 없는 S 기록 설명을 표시합니다.

Windows와 Android 모두 0.11.11입니다. Android versionCode는 39이며 기존 정식 패키지·서명을 유지합니다. 기존 설치판 위에 업데이트하세요.

사용자가 제공한 과거 JSON은 로컬 재생에서 4/4 S로 확인했습니다. 현재 계정의 최신 API 응답과 실제 기기 화면은 별도 확인이 필요합니다. [판정 기준과 검증 범위](../SHIYU_RECORDS.md)
