# 사이퍼링크 0.11.10

- Windows 업데이트 설치 중 자동 닫기를 선택했을 때, 종료 요청에 응답하지 않는 프로세스가 남아 파일 교체가 막히는 경우를 보강했습니다.
- 설치 대상 파일을 사용하는 프로세스를 Windows Restart Manager의 강제 종료 방식으로 닫도록 설정했습니다. 임의의 Python 프로세스나 다른 경로의 실행 파일을 이름만으로 종료하지 않습니다.
- 숨겨진 창과 보이는 창 각각에서 종료 요청을 거부하고 EXE를 잠근 프로세스를 실제 Windows CI로 검증한 뒤 배포합니다.
- 기존 계정·설정·DB를 지우거나 기존 앱의 창 닫기·예약 동작을 변경하지 않습니다.

Windows와 Android의 표시 버전은 모두 0.11.10입니다. Android는 기존 정식 패키지·서명을 유지하며 versionCode만 38로 증가합니다.

업데이트할 때 진행 중인 계정 연결이나 입력 작업은 먼저 마무리하세요. 0.11.10 설치 프로그램에서 응용 프로그램 자동 닫기를 허용한 뒤 진행합니다. 사용자 기기의 권한·보안 프로그램에 따른 차이는 별도 확인이 필요합니다.
