Windows와 Android 설치 파일을 같은 버전으로 제공하는 첫 GitHub 릴리스입니다.

| 기기 | 받을 파일 |
| --- | --- |
| Windows PC | **CipherLink-Windows.exe** |
| Android 휴대폰 | **CipherLink-Android.apk** |

아래 **Assets(파일)**에서 설치 파일을 누르세요. `Source code`는 개발용이므로 받지 않아도 됩니다. Windows는 EXE를 실행하고, Android는 APK를 열어 업데이트하세요. 비공개 저장소는 GitHub 로그인이 필요합니다.

### 달라진 점

- 진행도 버튼이 다른 작업 때문에 무시되던 문제 수정. 조회 중인 게임과 로딩 표시를 상단에 제공합니다.
- 스타레일 주간 조건을 **통합 포인트 18,000점 이상 + 역전의 여운 주간 보상 잔여 0/3**으로 맞췄습니다. PC와 Android 모두 적용했습니다.
- 진행도와 실시간 메모의 중복 표시를 정리했습니다.
- 플로팅 버튼에 사이퍼링크 아이콘을 사용합니다. 앱 연결 목록에는 연결한 게임 앱의 아이콘을 표시합니다.
- 모든 앱 보기에서 검색할 수 있습니다. Todoist 라벨로 새 게임을 등록해 앱과 연결할 수 있습니다. 신규 게임은 수동 체크를 지원합니다.
- PC·Android 설정에서 현재 버전과 최신 다운로드 페이지를 열 수 있습니다.

### 설치·업데이트

- 설치에 성공한 기존 테스트 앱(0.11.1/0.11.2) 위에 업데이트하세요. 앱의 내부 패키지와 서명을 유지합니다. 원래 0.10.2와는 별개입니다.
- Windows를 종료한 뒤 새 EXE로 교체하세요. 설정과 데이터 폴더를 삭제하지 마세요.
- 전체 비공개 배포를 선택했으므로 앱은 브라우저에서 릴리스 페이지를 엽니다. 무인 자동 조회/설치 대신 GitHub **Watch → Custom → Releases**로 새 버전 알림을 받을 수 있습니다.

실계정 API·Android17 실제 설치와 화면 조작, Windows EXE 실제 실행은 **미검증**입니다. 빌드·회귀 테스트 결과와 실환경 검증을 구분합니다. 체크섬은 `SHA256SUMS.txt`로 제공합니다.

검사: PC 회귀 테스트 **244개 통과**, Android APK 빌드·서명·0.11.1→0.11.3 업데이트 메타데이터 검사 통과. 진행도·라벨·메모 관련 Kotlin 회귀를 포함한 21개 테스트 프로그램 통과. Windows 빌드는 릴리스 CI 결과로 별도 기록합니다.
