# Android 0.10.5 임시 테스트판

사용자 요청으로 API 확장은 보류하고 APK 우선 제공. versionCode26. 목표 점수와 현재 회차/예정일이 확인되면 첫 조회에서 즉시 완료한다. PC/Android의 2회 관측 대기를 제거했으며 중복 UUID와 현재 회차 검증은 유지한다. Todoist Sync 성공 응답 뒤에만 작업명 알림을 보낸다. Android13+ 알림 권한을 허용하고 할 일 → 완료 팝업 알림 설정에서 팝업을 켠다. 방해금지/절전/시스템 설정에 따라 팝업이 표시되지 않을 수 있다.

일반 업데이트판: 기존 applicationId 유지, 이전 클라우드0.10.4 APK와 동일 서명, versionCode25→26. 기존 설치앱의 실제 서명/버전은 확인할 수 없으므로 설치 실패 원인은 아직 확정하지 않는다.

별도 설치 테스트판: -PcipherlinkPreview=true, com.gametodo.nativeapp.preview, 표시 이름 사이퍼링크 테스트. 기존 앱을 삭제하지 않고 독립 설치하며 기존 로그인/설정은 읽지 않는다. 별도 로그인 후 기존 앱과 동시 자동 동기화하지 말고 테스트한다. 정식 앱의 패키지/키는 변경하지 않는다.

PC224 tests 통과. Kotlin CompletionDispatch 테스트는 서버 승인→기록→알림 순서, 서버 실패 시 알림 없음, 알림 실패가 성공한 완료를 취소하지 않음을 검증했다. Android 전체 빌드와 서명 검증 결과는 산출물 검사로 확인한다. 실제 휴대폰 업데이트·로그인·팝업 표시는 미검증이다.

미검증 공개 API는 실제 요청해 스텔라KR 배너와 명조CN Wiki JSON을 수신했다. 신규 어댑터는 아직 구현하지 않았으며 이 임시 APK에는 포함하지 않는다.
