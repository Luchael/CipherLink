# 사이퍼링크 0.11.0 사용 화면 개선

## 확인된 문제와 수정

1. Android의 기존 Todoist 버튼은 저장된 세션 확인만 호출했고, 실제 TodoistAuth.login 호출이 사용자 화면에 없었다. 홈/계정에 공식 브라우저 연결·재연결 버튼을 추가했다.
2. 공식 Doist SDK의 인증 주소는 todoist.com/oauth/이고 데이터 API 주소는 api.todoist.com/api/v1/이다. 등록/승인/교환 주소를 정정했다. 공개 client none+PKCE를 유지하고 콜백을 IPv4 loopback으로 명시한다. 잘못된 state·favicon 요청이 로그인 대기를 소모하지 않게 했다.
3. 공식 SDK에서 expires_in과 refresh_token은 선택사항이다. 만료가 없는 세션에 1시간 만료를 만들지 않는다. 새 클라이언트 준비 중 기존 정상 세션을 덮어쓰지 않고, UI 렌더링 중 네트워크 갱신을 하지 않는다.
4. 게임 화면 표시와 게임 실행 시 자동 조회를 별도 설정으로 저장한다. Android 접근성 권한은 게임 구분에 공유하지만 기능 스위치는 독립이다. 표시를 끄면 즉시 숨기며 주기 동기화/게임별 조회 선택을 변경하지 않는다.
5. Android의 시험 API 조회·진단 JSON 내보내기·패키지 직접 입력·중복 점검 버튼을 제거했다. 홈/계정/할 일/설정으로 정리하고 밝은 배경·대비·여백·48dp 이상 터치 영역을 적용했다. 게임 선택에는 설치된 앱 아이콘, 현재 연결, 단일 선택 표시, 명시적인 저장과 해제를 제공한다. 외부 이미지 다운로드 없이 설치된 게임 이미지를 사용한다.
6. 상세 진행도는 게임·캐릭터별 카드와 목표/수치/진행률/회차 상태로 표시한다. 0/9는 진행 전이며, 목표가 없는 값은 정보 없음으로 구분한다. PC에도 스크롤 가능한 진행도 페이지와 카드/막대를 추가하고 점검용 버튼을 정리했다. 자동 완료 기준과 Todoist 제목은 바꾸지 않았다.
7. 설치에 성공한 .preview 패키지·서명을 유지하고 versionCode28, 표시 이름 사이퍼링크, versionName0.11.0으로 배포한다. 테스트 앱 위 업데이트이며 원래0.10.2 앱의 서명이나 데이터를 변경·통합·삭제하지 않는다.

## 근거와 검증

OAuth 공개 근거: 공식 [Doist SDK endpoints](https://github.com/Doist/todoist-api-typescript/blob/dd0b75a214d7a1bfc19ae8ed7e14a823aa1b2ca0/src/consts/endpoints.ts), [authentication](https://github.com/Doist/todoist-api-typescript/blob/dd0b75a214d7a1bfc19ae8ed7e14a823aa1b2ca0/src/authentication.ts). PC 계약 테스트는 변경 전 주소/만료 실패를 확인한 뒤 통과했다.

PC236 tests 통과. 새 Kotlin 회귀3개는 OAuth 주소·만료·callback, 표시/실행조회4조합의 독립성, 0점·정보없음·목표달성 표시를 검증한다. Android 전체 APK 빌드 통과. 이전 설치성공 APK27과 비교해 동일 서명·패키지의 상위버전28임을 확인했고 서명/ZIP검증도 통과했다.

PC Tk8.6 가상 디스플레이에서 계정/진행도 화면을 실제 렌더링하고 한글·스크롤·0점/미확인 카드 표시를 검토했다. 화면 예시는 합성 데이터다.

클라우드의 Todoist 공식 호스트 접근은 현재 네트워크 정책으로 차단돼 있다. 필요한 호스트를 기존 허용 목록을 보존해 환경 설정 초안에 추가했으나, 초안 저장은 실행 중 정책 적용이 아니다. 휴대폰 브라우저의 실계정 OAuth 승인·Android17 화면/팝업·실제 설치 업데이트는 사용자 기기에서 추가 검증이 필요하다. Windows EXE 실행은 미검증이다.
