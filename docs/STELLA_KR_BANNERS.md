# 스텔라소라 KR 공개 가챠 연결

비공식 공개 API `https://api.ennead.cc/stella/banners?lang=KR`의 실제 응답을 수신하고 PC HttpClient 수집 경로에서 한정 캐릭터 픽업2개를 파싱했다. 기준 표본은 tests/fixtures/stella_kr_20261028.json이며 공개 일정 필드만 포함한다. API는 공식 게임사 API가 아니므로 추후 스키마/일정 변경 시 수집을 보류한다.

한국어 `여행가 기간 한정 모집`만 수집하며 5성 rateUp.entries의 한국어 이름을 사용한다. 레코드/상시/선택모집, 정보가 비어있는 배너는 제외한다. current 라벨을 믿지 않고 offset이 있는 시작·종료 시각과 현재기간을 검증한다. 원본+08:00은 KST+09:00으로 변환하며 PC/Android 키가 같다.

실제 확인표본: 세이나(기원) 2026-10-20 13:00 KST~2026-11-10 11:59:59 KST, 호타루 2026-10-27 13:00 KST~2026-11-17 11:59:59 KST. 개인 진행도/일퀘 API가 아니므로 자동 완료 지원으로 확대 해석하지 않는다. Todoist 실제 쓰기는 실행하지 않았다.

PC 새 설정에서는 source=ennead, enabled=true. 기존 사용자가 enabled=false로 설정했으면 선택을 보존한다. Android는 PC 없이 자체 동기화한다. 새 APK 버전27/0.10.6-alpha에는 스텔라 경로와 이전 즉시 완료/성공알림 변경을 포함한다. 업데이트판은 기존 패키지·서명을 유지하며 테스트판은 별도 .preview 패키지이다. 실제 기기 설치·팝업 표시는 미검증이다.

검증: PC227 tests 통과. 실제 JSON의 Kotlin 파서 테스트에서 두 캐릭터·PC/Android 키 일치·KST·오류기간/만료 제외 확인. 기존 OCR 테스트의 시각 의존성은 테스트 시간을 고정해 해소했다.

명조 CN Wiki 공개 응답도 확보했다. 캐릭터 등급/한국어 연결과 종료 분 정밀도는 추가 검증이 필요해 직접 CN 어댑터는 아직 미구현이다. 리버스/림버스/명조/스텔라의 개인 진행도 API 확장은 이번 APK에 포함하지 않는다.
