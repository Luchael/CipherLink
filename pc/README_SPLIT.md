# GameTodo PC v0.8.0-source

v0.7.x Windows Python 앱 유지, 103개 회귀 테스트 통과. Android와 동일한 Todoist 계정으로 독립 로그인할 수 있습니다.

보호 조치: 명조 글로벌 사용자의 잘못된 KR 팬 캘린더 가챠 생성 위험을 막기 위해 `gametodo/banners.py`의 신규 wuthering 수집을 보류합니다. 검증된 글로벌 Asia 공개 출처가 생기면 재활성화하세요.

실행: `run_windows.bat` 또는 CMD에서 `python -m gametodo ...`. `config.json`, `data/`는 기존 설치에 남겨두세요.
