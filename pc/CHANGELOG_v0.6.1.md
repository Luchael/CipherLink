# GameTodo v0.6.1 수정 내역

- 이전 GUI는 인증값이 저장된 것만으로 Todoist를 '연결됨'이라 표시했음. 실제 `/projects` API 검증을 추가.
- HTTP 401/403/404/429, DNS, 응답형식, 프로젝트·섹션 오류를 비밀정보 없이 분류.
- Todoist 섹션 목록을 로드하여 GUI에서 수집 대상 섹션을 한 번 선택하고 ID 저장.
- HoYoLAB 로그인 후 아시아 서버의 원신·스타레일·젠존제 UID를 자동 탐색·활성화.
- SKPORT, KuroBBS 브라우저 기반 계정 조회를 조건부 구현. 토큰/지역 확인 실패 시 비활성화.
- 명일방주 KR Yostar 이메일 인증 다이얼로그를 추가 (계정 실사용 검증 전).
- 게임 로그인 의존성 설치 버튼 및 `requirements-login.txt` 추가.
- `python -m gametodo doctor` 진단 명령 추가.
- 자동 조회 중지/재시작 시 이전 워커가 되살아나지 않도록 stop Event 분리.
- SQLite 동시 접근 busy timeout 20초 설정, 게임별 수집 오류를 화면에 표시.
- 기존 일반 이벤트 미수집, 가챠 자동 완료, 기존 Todoist 중복 방지, 기존 일정 및 컬러스위퍼 제외 유지.
- 모의 데이터 기반 단위 테스트 90개 통과. Windows 실제 로그인/빌드/휴대폰 실기기 미검증.

확실하게 자동 연결을 지원하는 공개 계정 API가 없는 게임은 연결됐다고 표시하지 않음.
