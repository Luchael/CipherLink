# GameTodo Auto Sync v0.6.0 변경 사항

- 일반 이벤트 일정 수집/생성 파이프라인을 실행 경로에서 제거했습니다. **기존 Todoist 일반 이벤트는 건드리지 않습니다.**
- 한국 서버 캘린더에서 현재 진행 중인 캐릭터 **픽업/복각만** 추출합니다. 캐릭터명을 파악할 수 없거나 한국 서버가 확인되지 않는 항목은 건너뜁니다.
- `[원신] 캐릭터`, `[열차] 캐릭터`, `[젠존제] 캐릭터`처럼 기존 접두사·라벨 체계를 사용합니다. 버전이 확인되거나 설정되면 이름 뒤에 `(버전)`을 추가합니다.
- `due`/`deadline`을 쓰지 않습니다. 프로그램이 종료 시각+최대 1분 후(분 단위 데이터) `item_close`를 보내 마감 처리합니다.
- 중복 감지 ID는 같은 일정의 시작 시각/캐릭터/게임으로 고정합니다. 기존 수동 작업과 0.5.x 일반 이벤트는 자동 완료하지 않습니다.
- Windows 브라우저 로그인 기반 Todoist OAuth 동적 클라이언트 등록 및 만료 토큰 갱신 기능 추가.
- HoYoLAB 로그인 후 브라우저 계정 세션을 가져오는 선택 기능 추가(브라우저 정책에 따라 작동 제한).
- Tkinter GUI, 초기 설정 파일 자동 생성, Windows 로그인 후 자동 시작 등록 기능 및 PyInstaller EXE 빌드 스크립트 추가.
- Android에서는 기존 Kotlin 플로팅 앱·Termux Python 엔진 유지, 직접 APK 빌드는 미수행.
- 한국어 설명 주석, 기존 일일·주간·엔드콘텐츠 코드 유지.
- 오프라인 모의 테스트: 총 81개 통과. **Todoist 실제 로그인/가챠 페이지 실시간 수집/Android 실기기/Windows EXE 빌드는 검증하지 못했습니다.**
