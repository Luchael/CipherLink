# PC 비식별 API 정밀 진단

1. 기존 PC 로그인/설정 유지. `pc` 디렉터리에서 `python -m pip install -r requirements-endgame.txt`.
2. `python -m gametodo.safe_diagnostic --config config.json` 실행.
3. `CipherLink_api_diagnostic_safe.json` 생성 후 파일 내용을 직접 확인하여 공유.
4. 명일방주 개인 계정은 자동 조회/자동 재로그인하지 않음. 글로벌 명조 일일 API 미검증.
5. 개인정보·토큰은 원문을 저장하지 않지만 점수/날짜 정보는 포함하므로 개인 데이터 여부 확인.
